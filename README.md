# SkillsQuark-DataScience-Internship

## About the Internship
This repository contains the tasks completed as part of the SkillsQuark Data Science Internship. The projects focus on data manipulation, statistical analysis, visualization, and predictive modeling using Python.

## Tasks Completed

### Task 1: Data Manipulation
- Created and explored a customer dataset.
- Removed duplicate records.
- Handled missing values.
- Performed column transformations.
- Saved the cleaned dataset as a CSV file.

**Tools:** Python, Pandas, NumPy

### Task 2: Statistical Analysis and Visualization
- Created a student performance dataset.
- Calculated mean, median, standard deviation, minimum, and maximum values.
- Visualized study hours, marks distribution, and correlations.
- Summarized key findings from the analysis.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

### Task 3: Predictive Modeling (Regression)
- Built a Linear Regression model to predict student marks.
- Split the dataset into training and testing sets.
- Evaluated the model using MAE, MSE, and R² score.
- Compared actual and predicted values using a chart.
- Generated predictions for a new student.

**Tools:** Python, Pandas, NumPy, Matplotlib, Scikit-learn
